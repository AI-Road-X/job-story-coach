# 求职故事教练（Job Story Coach）

帮助学生围绕目标岗位，把真实经历整理成简历要点、面试故事和作品集材料。工作流程按步骤推进：岗位与公司分析 → 经历素材盘点 → 故事提炼 → 简历优化 → 面试演练 → 作品集规划与复盘。

## 适用范围

本项目采用开放的 Agent Skills 文件结构（核心文件为 `job-story-coach/SKILL.md`）。可用于支持 Agent Skills 格式的 AI 助手；不同产品的安装目录和能力支持可能不同。不要把“支持该格式”理解为所有 AI 产品都能直接安装。

## 安装

### 使用 skills CLI

```bash
npx skills add AI-Road-X/job-story-coach --skill job-story-coach
```

如需查看 CLI 支持的选项：

```bash
npx skills add --help
```

### 手动安装

下载本仓库，找到 `job-story-coach/` 文件夹，并将整个文件夹复制到所用 AI 客户端的 skills 目录。若客户端支持上传 Skill，也可以上传包含 `SKILL.md` 的该目录。

## 开始使用

提供目标岗位 JD、公司简介和个人简历/经历素材，然后说：

> 请按求职故事教练的流程带我打磨这份申请。每次推进一步，先分析 JD 和公司，再帮我从真实经历中提炼证据；不确定的信息先问我，不要编造。

可以只提供已有材料；教练会逐步指出缺失的信息并协助补充。最终可产出岗位匹配分析、简历内容、面试回答、故事素材库和作品集建议。

## 真实性原则

所有经历、职责、数据与结果必须由使用者核实。AI 可以帮助组织表达，不应虚构项目、指标、职责或成果。投递前请人工核对事实、隐私和公司保密要求。
